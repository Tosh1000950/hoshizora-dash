# ほしぞらダッシュ（Hoshizora Dash）

ドット絵の横スクロールアクションゲームです。ブラウザだけで遊べます（スマホ・PC両対応、インストール不要）。

## 遊び方

GitHub Pages で公開しているページを開くと、そのまま遊べます。

- モード：ノーマル／ハード／タイムアタック／エンドレス
- キャラクター：てんてん／らぎたん（操作方法やルールの詳細はゲーム内の「あそびかた」をご覧ください）

## 操作

- PC：A／D キーで移動、W／スペースでジャンプ（長押しで高さ調整）、Shift でダッシュ、S／↓ で急降下、P／Esc でポーズ
- スマホ：画面のスティック（ぷにコン）とボタンで操作

## クレジット

- プロデューサー・企画・プログラム・デザイン：Tosh1
- 元のキャラクター：REALITYのアバター
- 利用AI：Muse・Gemini・ChatGPT
- キャラクター素材：ドット絵スプライト（全43ポーズ）
- 音楽・効果音：Web Audio 生成チップチューン
- 背景・ギミック描画：ドット絵（Chat GPT Canvas）
